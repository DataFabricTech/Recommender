# 개요

두 기능의 동작 방식을 정리합니다.

- **데이터 카테고리** — 데이터를 주제별로 묶고 카테고리 간 연결을 그래프로 산출
- **표준 용어 매핑** — 컬럼명이 표준 용어·단어·도메인 규칙에 맞는지 판정

---

# 데이터 카테고리

## 요구 사항

- 데이터를 미리 정한 주제로 분류
- 분류 결과를 카테고리 간 연결 관계가 보이는 그래프로 제공

## 왜 군집화와 매핑을 나누는가

주제를 직접 분류하려면 데이터마다 정답 주제를 붙여야 합니다. 대상이 불특정 다수의 메타데이터라 현실적이지 않습니다.

두 단계로 나눕니다.

| 단계 | 방식 |
|---|---|
| 1. 군집화 | 메타데이터 임베딩을 K-Means로 묶습니다. 정답 없이 구조만으로 나눕니다 |
| 2. 카테고리 매핑 | 각 군집의 중심 벡터를 **사전 정의 카테고리의 키워드 임베딩**과 비교해 1:1로 배정합니다 |

군집은 데이터가 정하고, 이름은 사람이 정한 카테고리에서 가져옵니다.

## 1:1 배정을 쓰는 이유

군집마다 가장 가까운 카테고리를 각각 고르면 **여러 군집이 같은 카테고리로 몰립니다.** 그러면 비어 있는 카테고리가 생기고 분류가 한쪽으로 치우칩니다.

군집 수와 카테고리 수를 맞추고 헝가리안 1:1 최적 배정을 적용해, 전체 유사도 합이 최대가 되도록 배정합니다.

## 카테고리 키워드

각 카테고리는 이름과 **매칭용 키워드 문장**을 함께 가집니다. 키워드는 군집 중심과의 임베딩 유사도 계산에 쓰입니다.

메타데이터가 한국어와 영어가 섞여 있어 키워드도 양쪽을 함께 둡니다. 실제 데이터 성격에 맞춰 이름과 키워드를 조정하면 매칭 품질이 올라갑니다.

## 구현

| 모듈 | 역할 |
|---|---|
| `app/services/categories.py` | 사전 정의 카테고리와 키워드 |
| `app/services/category_graph_builder.py` | K-Means 군집화, 1:1 배정, 그래프 생성 |

# 표준 용어 매핑

## 요구 사항

- 컬럼명이 조직의 표준 용어 체계에 맞는지 판정
- 맞지 않으면 대체할 표준 용어를 추천

## 판정 순서

위에서부터 차례로 보고, 맞으면 멈춥니다.

| 순서 | 판정 | 성공 시 추가 확인 |
|---|---|---|
| 1 | 컬럼명 전체가 **표준 용어**와 일치하는가 | 용어의 도메인 자료형과 **길이**를 컬럼과 비교 |
| 2 | 컬럼명을 토큰으로 쪼갰을 때 **모든 토큰이 표준 단어**와 일치하는가 | 형식 단어의 도메인 자료형 계열을 비교 |
| 3 | 둘 다 실패 | 대체할 표준 용어를 추천 |

2단계에서 길이를 검사하지 않는 이유는, 표준 단어가 도메인 분류명에 여러 길이로 매핑되기 때문입니다. 단어 단위로는 길이를 특정할 수 없습니다.

## 자료형을 계열로 비교하는 이유

원천 컬럼의 자료형은 DB마다 제각각입니다 — `INT`, `TEXT`, `VARCHAR2(128)`, `NUMBER`, `STRING` 등. 반면 표준 도메인의 자료형은 소수의 종류뿐입니다.

그대로 비교하면 같은 의미인데도 불일치로 판정됩니다. 양쪽을 **문자·숫자·날짜 계열로 정규화한 뒤** 계열이 같은지로 판정합니다.

`CHAR`와 `VARCHAR` 같은 문자 내부 차이는 원천마다 표현이 달라 구분하지 않습니다.

## 추천을 두 단계로 두는 이유

표준에 맞지 않는 컬럼에 대체 용어를 추천할 때, 토큰이 정확히 겹치는 후보를 먼저 찾습니다. 정확 겹침이 없으면 추천이 비게 되므로 **퍼지 매칭으로 보완**합니다.

| 단계 | 방식 |
|---|---|
| 1 | 토큰 정확 겹침 기반 추천 |
| 2 | 1이 비었을 때 퍼지 매칭으로 후보 제시 |

## 컬럼명 토큰화

표준 단어와 대조하려면 컬럼명을 단어 단위로 쪼개야 합니다. 구분자·대소문자·약어 표기가 원천마다 다르므로 토큰화 단계에서 정규화합니다.

## 구현

| 모듈 | 역할 |
|---|---|
| `standard_mapping/service/rule_matcher.py` | 3단계 판정 |
| `standard_mapping/service/tokenizer.py` | 컬럼명 토큰화와 정규화 |
| `standard_mapping/service/type_normalizer.py` | 자료형 계열 정규화 |
| `standard_mapping/service/recommender.py` | 토큰 겹침 기반 추천 |
| `standard_mapping/service/recommender_fuzzy.py` | 퍼지 매칭 추천 |
