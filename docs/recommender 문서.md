# 비지도 학습의 필요성

- 지도학습은 데이터의 label(정답)이 지정되어야 학습이 가능하지만, **불특정 다수의 메타 데이터**의 경우 label을 수동으로 지정하는 것은 거의 불가능에 가까워, 지도 학습을 어렵게 만듭니다. 데이터 카탈로그 추천은 label이 없는 데이터의 구조를 분석하고, 자동으루 군집화하여 효율적으로 처리하고자 합니다.

# 비지도 학습 알고리즘의 종류

- **K-Means Clustering**
  - 각 군집의 평균(mean)을 활용하여 K개의 군집으로 묶는 알고리즘
- **Mean-Shift Clustering**
  - 데이터 분포의 peak 또는 무게중심을 찾는 방법
- **Density-Based Spatial Clustering of Applications with Noise(DBSCAN)**
  - 밀도 기반으로, 서로 가까운 데이터 포인트를 함께 그룹화 하는 알고리즘
  - 밀도가 다양하거나 모양이 불규칙한 클러스터가 있는 데이터와 같이 모양이 잘 정의되지 않는 데이터릴 처리할 때 유용하다.
- **Gaussian Mixture Model을 사용한 Expectation-Maximization(EM) Clustering**
  - 데이터 분포가 여러 개의 Gaussian 분포 여러개가 섞여서 만들어졌다고 생각하고, 해당 데이터 분포를 이루는 여러개의 Gaussian 분포로 나타내는 확률적 생성 모델
- **Agglomerative Hierarchical Clustering**
  - 데이터 포인트들을 거리나 유사도 기반으로 계층적으로 묶어나가는 군집화의 방법

### 각 알고리즘에서 요구사항과 반대되는 사항들

- **K-Means Clustering**
  - 군집화의 갯수를 선정의 어려움
  - 비구형 군집 및 이상치가 많은 경우 어려움
- **Mean-Shift Clustering**
  - 대규모 데이터 셋 처리의 어려움
- **Density-Based Spatial Clustering of Applications with Noise(DBSCAN)**
  - 대규모 데이터 셋 처리 비교적 어려움
  - 메모리 사용량 중간
  - 속도 중간
- **Gaussian Mixture Model을 사용한 Expectation-Maximization(EM) Clustering**
  - 군집화의 갯수를 미리 정해야한다.
  - Computing Cost 높다
  - 대규모 데이터 셋 처리의 어려움
  - 메모리 사용량 높음
- **Hierarchical Clustering**
  - Computring Cost가 높다.
  - 대규모 데이터 셋 처리의 어려움
  - 메모리 사용량 매우 높음

## 상세 알고리즘 비교 분석(K-Means Clustering VS DBSCAN)

#### K-Means Clustering

##### 장점

- 단순성과 효율성
  - 구현이 간단하고, 대규모 데이터셋에 대해서도 비교적 빠르게 동작, **큰 데이터셋에서도 사용하기 적합**
- 확장성
  - 데이터셋이 커질수록 성능 저하가 덜하며, **대규모 데이터를 다루는 데 효율적**이다.

##### 단점

- 군집의 형태에 민감함
  - K-Means는 **구형 군집**을 가정하므로, **군집의 모양이 비구형이거나 복합한 형태일 경우 정확하지 않은 결과**를 낼 수 있다.
- 초기값에 대한 민감성
  - 초기 중심값 설정에 따라 최정 결과가 크게 달라질 수 있으며, 최적의 중심값을 찾기 위해 **여러 번 초기화**를 시도해야 할 수 있다.
- 군집 수(K)를 사전에 정의
  - K 값을 미리 설정해야 하는데, 적절한 K값을 선택하는 것이 어려울 수 있다.
- 노이즈와 이상치에 민감
  - K-Means는 모든 데이터를 군집에 포함시키기 때문에 노이즈나 이상치 데이터가 포함되면 군집화 결과에 부정적인 영향을 미칠 수 있다.

#### DBSCAN

##### 장점

- 비선형 구조와 다양한 밀도의 군집 탐지
  - 군집이 비구형이거나, 밀도가 **다를 때도 효과적**으로 작동하여 다양한 형태의 데이터에 적용 가능하며, 복잡한 데이터 구조를 잘 처리한다.
- 노이즈 처리
  - 밀도가 낮은 데이터 포인트를 자동으로 노이즈로 간주하여 군집화에서 제외하여, **이상치가 많거나 노이즈가 포함된 데이터에 유리**
- 군집 수를 사전에 알 필요 없음

##### 단점

- 매개변수 설정이 어려움
  - 입실론 및 최소 포인트 수라는 매개변수에 매우 민감하여, 적절히 설정하지 않으면, 군집화 결과가 크게 달라질 수 있다.
- 고차원 데이터에 비효율적
  - 고차원 데이터에서 효율성이 떨어질 수 있으며 군집화 성능이 저하될 수 있다.
- 데이터셋 크기에 따라 성능 저하
  - **매우 큰 데이터셋**에서 **계산 비용이 증가**하며, 처리 속도가 느려진다.

# DBSCAN을 채택한 이유

- 대상 데이터는 메타 데이터를 이용한 문자열 데이터로써, **구형 군집을 이루지 못한다.**
- 불특정 다수의 메타 데이터로써, **이상치와 노이즈가 생겨나는 구조의 데이터 세트이다.**
- 자동 추천 시스템이 목적이므로, **군집의 갯수(K)를 수동으로 설정할 수가 없다.**
