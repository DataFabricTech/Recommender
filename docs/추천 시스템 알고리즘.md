- 추천 시스템에서 주로 사용하는 알고리즘의 종류

  - 협업 필터링
    - 사용자 기반 협업 필터링
      - 비슷한 행동 패턴을 가진 사용자들이 선호하는 아이템을 추천
      - 나와 비슷한 취향을 가진 사용자가 좋아하는 영화 추천
    - 아이템 기반 협업 필터링
      - 유사한 아이템끼리의 관계를 기반으로 추천
      - 특정 영화를 본 사용자가 자주 시청한 다른 영화를 추천
    - 행렬 분해
      - 대표 알고리즘
        - SVD
        - ALD
        - NMF
      - 사용자-아이템 상호작용 데이터를 저차원 벡터로 표현하여 유사도를 계산
    - 딥러닝 기반 협업 필터링
      - Autoencoder: 사용자-아이템 상호작용 데이터를 재구성하여 패턴 학습
      - Neural Collaborative Filtering: 신경망을 활용해 사용자와 아이템 간 복잡한 관계를 모델링 
  - 콘텐츠 기반 필터링
    - 사용자가 이전에 선호했던 아이템과 유사한 특성을 가진 아이템을 추천
      - 사용 알고리즘
        -  TF-IDF, Word2Vec
        - Cosine Similarity, 유클리디안 거리 (유사도 계산)
        - CNN, RNN
      - 사용자가 좋아하는 영화의 장르, 감독, 배우 정보를 분석해 유사한 영화 추천
  - 하이브리드 방식
    - 협업 필터링과 콘텐츠 기반 필터링을 결합하여 각각의 단점을 보완
      - 협업 필터링의 결과를 콘텐츠 기반 필터링으로 보완
      - 두 방식의 결과를 가중치를 두고 결합
      - Meta-Algorithm으로 결과 통합

- 비정형 데이터의 추천 시스템 구축 방법

  - 비정형 데이터란?
    - 정형화되지 않은 데이터로, 텍스트, 이미지, 오디오, 비디오 등이 포함
  - 추천 방법
    - 텍스트 데이터 기반
      - 사용자 리뷰, 상품 설명 등 텍스트 데이터를 활용
      - 텍스트 임베딩: TF-IDF, Word2Vec, GloVe, BERT 등을 사용해 텍스트 데이터를 벡터로 변환
      - 유사도 계산: 코사인 유사도, 유클리드 거리 등을 사용해 사용자와 아이템 간의 유사도 계산
      - 감석 분석: 리뷰의 감정을 분석하여 추천에 반영
    - 이미지 데이터 기반
      - 상품 이미지, 사용자 프로필 사진 등
      - CNN을 활용한 이미지의 특성 벡터 추출
      - 유사한 이미지를 가진 상품 추천
    - 비디오 데이터 기반
      - 동영상 스트리밍 플랫폼에서 콘텐츠 추천
      - 프레임별 특징 추출 (CNN, RNN)
      - 동영상의 메타 정보와 사용자의 시청 기록을 결합한 추천
    - 오디오 데이터 기반
      - 음악 추천, 팟캐스트 추천
      - MFCC, Spectrogram 같은 오딛오 특성 추출
      - 딥러닝 기반 모델(RNN, Transformer)로 특징 벡터 생성 및 추천
    - 다중 모달 데이터
      - 다양한 형태의 데이터를 결합하여 추천
        - 텍스트, 이미지, 메타 데이터 등을 결합하여 다중 모달 딥러닝 모델 구축
    - 텍스트 데이터 기반 추출을 선택한 이유는?
      - 정형 데이터와 비정형 데이터 모두 추천하기 위해서는 통일된 추천 시스템이 필요하다. 이미지, 비디오, 오디오, 다중 모달 데이터 기반의 추천 시스템을 구성하게 되면 정형 데이터를 추천하기 힘들어 지기 때문에, 정형 데이터와 비정형 데이터에서 메타 데이터를 추출하고, 추출된 메타 데이터를 이용하여, 텍스트 데이터 기반의 추천 시스템을 구축하였다.

- 비지도 학습과 지도 학습이란?

  - 지도 학습
    - 개념
      - 레이블이 있는 데이터를 사용하여 모델을 학습
      - 데이터에는 입력과 출력이 쌍으로 존재
      - 입력 데이터와 레이블 간의 관계를 학습하여 새로운 입력에 대해 정확한 예측을 수행
    - 특징
      - 데이터: (X,Y) 형태
      - 학습 과정: 모델이 레이블 Y를 예측하는 방법을 배우는 과정
      - 결과: 명확한 출력 갑(분류 결과, 예측 값등)
    - 대표적인 알고리즘
      - SVM, KNN,Decision Trees, Random Forest, Neural Networks
  - 비지도 학습
    - 개념
      - 레이블이 없는 데이터를 사용하여 모델을 학습
      - 데이터에 대한 사전 지식이 없으며, 데이터의 숨겨진 패턴이나 구조를 탐색
      - 목표: 데이터 내의 그룹화(클러스터링), 차원 축소 등 데이터 특성을 이해
    - 특징
      - 데이터: X형태
      - 학습 과정: 데이터의 분포나 패턴을 학습
      - 결과: 데이터 구조(클러스터), 축소된 데이터 표현
    - 대표적인 알고리즘
      - 클러스터링
        - K-means
        - DBSCAN
        - 계층적 클러스터링
      - 차원 축소
        - PCA
        - t-SNE
        - UMAP
      - 연관 규칙 학습
        - Apriori
        - FP-Growth
  - 비지도 학습을 선택한 이유
    - 불규칙적인 대규모의 데이터셋은 레이블(정답)이 있는 데이터를 규정할 수 없으며, 규정하려고 하더라도, 사람의 수작업이 들어가야 한다.
      여러 종류의 데이터셋에 사람이 수작업으로 레이블을 지정한 다는 것 자체가, Datafabric의 개념과 맞지 않아 레이블(정답)을 사용하지 않은 비지도 학습을 선택하게 되었다.
  - 추천 시스템의 추천 알고리즘
    - 추천 시스템은 두가지 이상의 알고리즘을 사용하여, 추천 시스템을 구성해야한다.
    - 현재 구상중인 알고리즘으로는 Clustering과 Embedding이 있다.
      - 혼용의 장점
        - 고차원 데이터 처리
          - 임베딩을 통해 고차원 데이터의 복잡성을 줄임
          - 클러스터링이 효율적으로 작동할 수
